# Review my changes

Review my uncommitted changes using the `review-changes` skill from the ReviewLens plugin.

For every changed file, explain why it changed, what changed, what it might affect and how risky it is. Group the files by area of the repo, flag behaviour changes that have no tests, and end with an approval checklist. This is read-only: don't edit, stage or commit anything.

If I named files, folders or an area after the command, review only those.

# Review a pull or merge request

Review a GitHub pull request or GitLab merge request using the `review-pull-request` skill from the ReviewLens plugin.

Use the PR/MR number or URL I gave after the command. If I didn't give one, list the ones waiting for my review and ask which to open.

Split the files into lanes by area, explain why each file changed, what changed, what it might affect and its risk, show open comment threads and each reviewer's status, and suggest a verdict. Draft review comments, but don't post anything to GitHub or GitLab until I say so.
